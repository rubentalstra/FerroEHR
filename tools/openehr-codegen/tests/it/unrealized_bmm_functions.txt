# that gets implemented must be deleted from here in the same change. It only
# shrinks. Burn-down is tracked on the issue named in that test.

# exactly the classes with the most missing — 576 declared functions went

# the emitter maps to a Rust primitive or never emits at all stay out, because
# `Integer.add` is `i32`'s `+` and there is no `impl i32` to write; that boundary
