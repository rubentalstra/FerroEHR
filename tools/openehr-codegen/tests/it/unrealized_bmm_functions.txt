# Every BMM-declared function that no Rust method realizes, as
# <crate>/<generation>/<CLASS>.<function>.
#
# This list is a RATCHET, not an excuse: unrealized_bmm_functions_match_the_ratchet
# asserts the projection equals it EXACTLY, so a new gap fails the build AND a gap
# that gets implemented must be deleted from here in the same change. It only
# shrinks. Burn-down is tracked on the issue named in that test.
#
# It grew once, from 75 entries to 651, when the projection was corrected (#2247).
# The old one skipped any class with no *_impl.rs sibling, so it was silent about
# exactly the classes with the most missing — 576 declared functions went
# unreported. Nothing regressed; the instrument started telling the truth. Classes
# the emitter maps to a Rust primitive or never emits at all stay out, because
# `Integer.add` is `i32`'s `+` and there is no `impl i32` to write; that boundary
# is read from the emitter's own decision maps, never from a second list here.
