**Fidelity gate GREEN (commit b22f9b5bd):** `openehr-its/tests/fidelity.rs` reads the real openEHR_SDK canonical-JSON corpus through generated `openehr_rm` → **54 read OK, 0 failed, 8 documented exclusions** (raw-DB/flat path-keyed compositions ×2, a deliberate invalid fixture, ITS-REST contribution-request shape ×2 [`versions`=full ORIGINAL_VERSION not OBJECT_REF], one malformed DV_TEXT [`name` key vs `value`], two RM-1.1-era files omitting mandatory LOCATABLE.name/archetype_node_id). Exclusions are documented+enforced (a non-listed failure still fails the gate), like the AQL corpus. Three emitter/derive features this required:
- **Polymorphic-concrete enums:** a *concrete* class that also has subtypes (`DV_TEXT`→`DV_CODED_TEXT`, `DV_URI`→`DV_EHR_URI`, `PARTY_IDENTIFIED`→`PARTY_RELATED`, `OBJECT_REF`→`{LOCATABLE_REF,PARTY_REF}`, `AUDIT_DETAILS`→`ATTESTATION`) emits `{Name}` untagged enum over `{Name}Data` struct + immediate subtypes (`Emission::PolyEnum`). `enum_variants` returns *immediate* concrete children so enums nest by hierarchy (DATA_VALUE ⊇ DvText ⊇ DvCodedText) instead of double-listing. Was the root cause of the "ContentItem" failures (coded names).
- **Interval flag defaults:** `#[openehr(default = "true"/"false")]` added to the derive; emitter marks `Interval.*_included`→true, `*_unbounded`→false (archie omits them; a bounded limit is included by default). `field_default(owner,field)` in emit.rs.
- **Byte buffers → base64 String:** `Array<Octet>` (`DV_MULTIMEDIA.data`, `integrity_check`) is inline base64 text on the wire, so it maps to `String`, not `Vec<u8>`.
- Enum-variant recursion boxing now also fires when a variant reaches back to the enum via its own fields (`BMM_TYPE` ⊇ `BMM_CONTAINER_TYPE.base_type`).

**Lossless round-trip gate DONE (2nd `fidelity.rs` test):** deserialize → re-serialize → `semantic_eq(input, output)` proves no silent data loss. **53 lossless, 9 documented exclusions, 0 failed.** `semantic_eq` tolerates exactly three information-preserving diffs: object key order (structural compare), fields we omit that input stated empty (`null`/`[]` — OpenEhrType drops None/empty), and fields we materialize that input left implicit (`_type` always emitted; `Interval` `*_included`→true / `*_unbounded`→false defaults).
