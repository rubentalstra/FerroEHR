# The conformance catalogue

The machine-readable catalogue lives at `tools/cnf-runner/artifacts/`
(schedule cases, operation bindings, vocabularies, corpus, registers) — the
CNF 2.0 reference runner executes it and the committed per-SUT artifacts
under this directory are the only quotable numbers.

The former ECC catalogue document that lived here was generated by the
retired ECC harness (removed 2026-07-22, #202); its final inventory is
preserved at `tools/cnf-runner/comparison/ecc-catalog.tsv` and the reviewed
cutover record is `cnf-comparison.md`.
