## Scope note (from chapter notes)

Ingestion-side artefact validity is claimed to have landed at B2 task 6. The
highest-value requirements below are the **rejection duties** — the `Vxxx`
validity codes (AOM2 validation phases) and the `Sxxx` cADL syntax-error codes
(ADL2) that MUST reject a malformed/invalid OPT at upload with the corresponding
AOM2/ADL code. Each such code that is silently accepted is a leniency defect.
