**Scope note (generated-code caveat):** the `openehr-its` XML impls are `// @generated`; XSD structure proves the wire contract but not runtime rejection. Every "must reject" below is a Phase-2 verification target against the hand-written `xml/runtime.rs` reader + generated `FromXml` dispatch.
