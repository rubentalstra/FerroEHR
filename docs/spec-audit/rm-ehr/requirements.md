**Chapter-notes context (verified, not re-flagged):** the EHR_STATUS.subject monomorphic-slot leniency (anonymous `{}` / foreign `_type` acceptance) was fixed on develop in commit 360c44494 (PR #69) — `app/ehrbase/src/service/ehr.rs` `validate_ehr_status` now deserializes `subject` through the generated `PartySelf` type, and `crates/openehr-rm/tests/type_dispatch.rs` pins the derive rejection.
