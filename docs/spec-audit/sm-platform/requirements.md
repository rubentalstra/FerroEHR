**Focus:** interface pre/post-conditions actually *enforced* (not just trait signatures existing), `CALL_STATUS` mapping fidelity, transactional equivalence (every write = contribution + audit atomically), monomorphic-slot rejection duties.

> Note: SM interfaces are *abstract* (protocol-independent). Per master02 the binding constraint is **formal equivalence** — the pre/post-conditions and transactional semantics must hold regardless of how the native/REST implementation is decomposed. Requirements below are the machine-checkable residue of that.
