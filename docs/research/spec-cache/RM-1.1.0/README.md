AsciiDoc sources of the openEHR Reference Model component specifications,
cached so RM transcription reads the exact released text instead of memory or
a moving web page.

- Source repo: `github.com/openEHR/specifications-RM`
- Ref: tag `Release-1.1.0`, commit `3cbd85b`
- Fetched: 2026-07-02
- Layout:
  - `data_types/`, `data_structures/`, `common/`, `ehr/`, `demographic/`,
    `integration/`, `support/` — chapter masters

    ground truth

during the port, never edited.
